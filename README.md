## 关于我

你好，我是 **Vantchy**。

一名热爱简单事物的开发者。喜欢咖啡、纸质书和命令行。相信好的设计就是尽量少的设计。

这个博客没有固定的主题——技术笔记、读书感想、生活随笔，想到什么写什么。不追热点，不考虑流量，纯粹是写给自己的思考存档。

## 为什么叫「极简」

纯白背景。黑白灰配色。没有侧边栏，没有评论区，没有社交分享按钮。只有文字。

这个博客没有后端、没有数据库、没有框架。每一行代码都带着温度。
