你好，我是 Vantchy。欢迎来到我的博客。

这是一个完全由纯前端技术搭建的极简个人博客。没有后端服务器、没有数据库、没有评论系统——只有 HTML、CSS 和一点点 JavaScript。

## 技术架构

这个博客的核心理念是 **零依赖、零构建、零服务器**：

- 所有页面都是静态 HTML 文件。
- 文章以文件形式存放在 `posts/` 文件夹中，文件名格式为 `YYYY-MM-DD-标题.md`。
- 首页通过 JavaScript 读取 `index.json` 生成文章列表。
- 点击文章标题，内容通过 `fetch` 异步加载 Markdown 文件，客户端渲染，无需刷新页面。
- 不引用任何外部 CDN 资源，离线也能完整运行。

这意味着你可以把整个博客文件夹放在任何静态服务器上——GitHub Pages、Vercel、Netlify，甚至直接用浏览器打开都能运行。

## 为什么这样做

我厌倦了臃肿的技术栈。一个个人博客不应该需要 React + Webpack + GraphQL + 数据库。

> 「简单是可靠的副产品。」

越简单的系统，越不容易出问题。这个博客的整个代码量加起来可能还不如一个 create-react-app 的脚手架文件多。

## 如何新增文章

只需要两步：

1. 在 `posts/` 文件夹中新建一个 `YYYY-MM-DD-标题.md` 文件，写入文章内容。
2. 运行 `build.ps1`（或 `Ctrl+Shift+B`）自动更新 `index.json`。

刷新页面，新文章就出现了。没有构建步骤，没有部署流水线。
